# New Lab Members

We are located at MaRS Building Princess Margaret Cancer Research Tower\
101 College Street, 9th floor Room 303, \
Toronto, ON, M5G 1L7

## First day

* Sign up for [Slack Pugh Lab](https://slack.com/intl/en-ca/) group&#x20;
* Explore the Pugh Lab website: [www.pughlab.org](https://www.pughlab.org)
* Complete the **mandatory UHN MyLearning** training: [https://mylearning-uhn.sumtotal.host](https://mylearning-uhn.sumtotal.host)
* Setup VPN:&#x20;
  * **UHN Multi-Factor Authentication**: [https://mfa.uhn.ca/main.aspx](https://mfa.uhn.ca/main.aspx)

## Connecting to UHN Wi-Fi&#x20;

* UHN-Guest-Wi-Fi is usable until you have your tID  &#x20;
*   UHN-wireless-corporate is the preferred Wi-Fi network &#x20;

    * In the event of a Code Grey UHN-Guest-WiFi _should_ be useable, but you will be limited in what you can access&#x20;

  * Note: This training is extremely important as you will be assigned your UHN email and login

* UHN Payment information [https://www.uhn.ca/corporate/For\_Staff/New\_Employees](https://www.uhn.ca/corporate/For_Staff/New_Employees)

* Set up a time to meet with Trevor (and find your lab buddy)
* Pugh Lab meetings every Friday @10am in room 9-710
* UHN Wetlab Orientation, transportation of dangerous goods (optional)

## Tasks to complete in the first month

* Receive access to the Pugh Lab High-performance Compute (H4H/Valinor). Our lab utilizes a high-performance computing cluster that is accessed by logging into a computer. Write to zhibin.lu@uhn.ca using your new @uhn.ca email address to request access to this system.
* Create a free Github account (github.com/pughlab): This is the repository for all software and documentation generated by the lab including wet lab protocols. You can sign up for a free account at github.com and then Jeff Bruce can add you to the Pugh Lab organization.
* Request Steph make an amendment to Biosafety Certificate for new wet lab staff
* Determine which grant you are on and add yourself to the grant (this can take >month)

## Setting up your website profile

The lab website [pughlab.org](https://www.pughlab.org) has a section for Lab members, and you need to make sure a profile is created for yourself. You can add a photo, add your name and a brief bio to the web page.
