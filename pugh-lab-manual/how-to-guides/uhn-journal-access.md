# UHN Journal Access

## For Post-docs

Postdoctoral fellows are issued T cards at Reader Registration Services at Robarts Library. You need a letter from Trevor on department letterhead detailing their appointment. Take the letter to Reader Registration Services at Robarts Library (Monday to Saturday, 9 am - 5 pm) to get their T card. Ask Caitlin to arrange for your letter. [http://onesearch.library.utoronto.ca/cards-faculty-staff#r-s](http://onesearch.library.utoronto.ca/cards-faculty-staff#r-s)

## UHN Journal / PubMed Access

I recommend using a different browser for the following changes as you will not have access to the internet if you're not connected to the network (due to the proxy change).

E.g. If your default browser is Chrome, use firefox. This way you can use Chrome for your every day needs and firefox to access research articles (this only works if you're on the network!).

**Instructions**

Firefox → Preferences → Advanced → Network → Connection settings → Manual proxy configuration:

* HTTP Proxy: webproxy-utor.uhnresearch.ca
* Port: 3128
* Check “Use this proxy server for all protocols”
