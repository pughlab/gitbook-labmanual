# Sample Naming Convention

&#x20;

Each sample is given a Pugh Lab ID as it is processed through the lab. This ID can be used to track the sample in biobanking system (ATiM) and/or the LIMS (MISO).&#x20;

&#x20;

The sample name should be in the following convention:

&#x20;

Project-SiteID-PatientID-Timepoint-Sample Type Code

&#x20;

Ex: XXX-\*\*\*-0001-T0-B, where:&#x20;

·      XXX is the 3- letter project code

·      \*\*\* is the site code (Usually 2-3 numbers or letters)

·      0001 is the Patient/Participant ID

·      T0 is the timepoint (Baseline)

·      B is the sample type code (buffy coat)

&#x20;
