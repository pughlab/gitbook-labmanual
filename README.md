Welcome to the Pugh Lab Manual repository! This repository serves as the central documentation hub and knowledge base for the Pugh Laboratory at the Princess Margaret Cancer Centre. Designed for lab members, collaborators, and contributors, it outlines our core laboratory protocols, software development standards, coding best practices (including guidelines for R, Python, and NGS data pipelines), and reproducible research workflows. Whether you are setting up your computational environment, contributing to our open-source toolsets, or looking for standardized guidelines on cancer genomics and bioinformatics analyses, you will find our shared resources and documentation here.
